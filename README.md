# Artillery Calculator for Iron Nest

## 🇺🇦 Українська

### Калькулятор наведення гармати для Iron Nest

Цей калькулятор допомагає швидко визначити необхідний кут наведення гармати, час польоту снаряда та інші параметри пострілу залежно від відстані й кількості порохових зарядів.

Калькулятор також містить графік залежності між відстанню та кутом наведення для 1–6 порохових зарядів, можливість переглядати останні розрахунки та окремий калькулятор часу пострілу. Калькулятор часу дозволяє ввести час появи ворога та кількість хвилин до моменту, коли ворог опиниться у потрібній точці, після чого автоматично визначає час, коли необхідно зробити постріл.

Доступне перемикання між українською та англійською мовами.

**Цей калькулятор повністю створений за допомогою ChatGPT — від розробки логіки та розрахунків до програмного коду, дизайну інтерфейсу та подальших виправлень і вдосконалень. Я не є програмістом і до створення цього проєкту ніколи не займався програмуванням.**

Калькулятор створений для зручності гравців та не є офіційним інструментом гри.

## 🇬🇧 English

### Artillery Calculator for Iron Nest

This calculator helps quickly determine the required gun elevation, shell flight time, and other firing parameters based on the distance and number of powder charges.

The calculator also includes a graph showing the relationship between distance and gun elevation for 1–6 powder charges, a history of the last five calculations, and a separate shot-timing calculator. The shot-timing calculator allows you to enter the time when an enemy appears and the number of minutes until the enemy reaches the required position, then automatically calculates when the shot should be fired.

The interface is available in both Ukrainian and English.

**This calculator was fully created with ChatGPT — from the calculation logic and programming code to the interface design, debugging, and further improvements. I am not a programmer and had never programmed before creating this project.**

This is a fan-made tool created for the convenience of players and is not an official game tool.
